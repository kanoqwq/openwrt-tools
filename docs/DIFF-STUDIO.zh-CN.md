# OpenWrt Diff Studio

完整解压固件 ZIP，保留全部目录。

- Windows：双击根目录 `OpenWrt-Diff-Studio.exe`，无需另装 Python。
- Apple Silicon Mac：打开根目录 `OpenWrt-Diff-Studio.app`，无需另装 Python。
- Python 命令行：`python OpenWrt-Diff-Studio.py --help`，需安装 Python 和相应依赖。

Diff Studio 与安装器共用包内 `tools` 后端。不要单独复制 EXE 或 APP；
不需要再下载一份工具，也不重复包含 boot、rootfs 或另一套 Python 运行环境。

选择设备当前所用的旧完整发布包，再选择目标新完整发布包，点击分析。
可以拖入 ZIP，核对型号、版本、文件变更和冲突信息，再生成更新包。
默认文件名包含型号、系统版本及新旧发布标识，也可自己选择输出名称。

生成的包包含网页可导入的 `update.ota` 和电脑更新入口。
可以在 OpenWrt 网页“系统补丁”导入，也可以完整解压生成包后，
运行 `OpenWrt-Updater.exe` 或 `OpenWrt-Updater.app`，连接设备并更新。
更新保留用户插件、配置和数据；本地文件冲突按界面提示处理。
更新过程中保持设备供电和连接，完成后按页面提示操作。

备份与恢复副本可在系统补丁页面管理；删除恢复副本需要二次确认。
只导入可信来源、适用于当前机型和起始版本的补丁。

## 在 LuCI 中生成与更新

系统补丁页面可以直接导入 `.ota`，也可以上传包含唯一 `.ota` 的完整更新
ZIP；后端只读取该补丁，忽略 Windows/Mac 更新器，不运行 ZIP 中的程序。
若上传的是没有 `.ota` 的完整固件，请使用页面下方的“生成差分包”。

两种方式均可生成能直接导入的单个 `.ota`：

- **当前版本 → 新版**：上传新版完整 ZIP，以保存的原始版本摘要为旧版。
  缺少基准时，直接显示独立的“首次初始化当前版本基准”（不折叠），导入与当前型号、版本
  及内核匹配的完整 ZIP，保存
  基准一次；后续成功应用带摘要的 OTA 会自动保存新版基准，撤销也会恢复。
- **旧版 → 新版**：上传两个完整固件 ZIP，可导出用于其他同型号设备的补丁；
  旧版与本机一致时，也会为本机保存该干净基准。

这两种方式均不把当前系统文件当作旧版来源，不采集用户密码、配置、短信
或插件内容。原有配置保护与文件冲突规则保持不变；没有增加整机一致性要求。

生成在独立后台任务中执行；仅在上传、生成期间读取进度，空闲不运行服务或
定时器。关闭网页不会取消任务，重新打开页面可继续查看。两种方式完成后都
弹出“下载 .ota／检查并刷入／稍后处理”；选择刷入仍需兼容性检查、内容审阅
和最后一次确认，生成本身不会写系统文件、boot、分区、NV 或重启设备。

生成会暂存完整 ZIP 和输出；E5 还需要一份解压后的只读 ext4 临时文件，位于
持久存储而非 RAM。处理完毕清理本任务暂存文件，保留最新 `.ota` 供下载。
空间不足时报告失败，不通过写入系统或删除历史备份来腾出空间。

生成区域显示保留包的占用空间，生成区域和结果弹窗均提供“删除生成包”。
确认后只删除这份 `.ota`，保留版本基准、恢复副本、已上传的完整固件和配置。
生成、校验或刷入占用互斥锁时拒绝删除；若另一页面重新生成了包，旧确认也会
失效。即使后续生成失败，原先保留的包仍可删除。下载本身不自动删除服务端包，
避免下载中断后无法重试；再次成功生成时会替换旧包，不累计多份结果。

生成器与桌面 Diff Studio 共用同一套 release reader、比较与校验代码。
只读 ext4 解析依赖的完整源码、许可证和固定版本校验记录随插件提供，
见 `runtime/luci-app-unisoc-ota/root/usr/lib/unisoc-ota/generator/THIRD-PARTY.md`。

### 网页校验与消息大小

上传后的解包、内容哈希及兼容性检查由事件启动的独立进程执行，和更新、生成
共用互斥锁。网页只在任务运行时查询进度，刷新后可继续查看；校验完成不会自动
刷入，仍需明确确认。上传内容变化会使本次审阅失效，刷入前还会核对审阅 ID。

RPC 仅返回有大小上限的审阅摘要，不传输完整 `release_index`、运行环境或软件包
数据库。完整数据仍用于本地校验，桌面／命令行协议也保留完整结果。ubus 默认
消息上限为 1 MiB，旧版网页返回完整版本索引可能超过该上限，导致 rpcd 连接
断开、`session` 登录对象同时消失；网页表现为导入超时和原密码被误报为无效。
此故障不代表账号文件已更改，不能用重置密码掩盖。离线对照脚本
`tests/ota_rpc_bus.py` 使用已有 OpenWrt 镜像，在不联网的临时容器中复现原故障
并验证精简响应后登录对象保留，不接触实机。

基准／差分生成进度显示实际阶段、已处理字节或文件数；只有当前阶段总量已知
时才显示百分比。文件索引等未知总量的阶段使用动画和实际文件数，不伪造整体
百分比。首次初始化入口直接展开，标题采用普通块元素，避免主题将其当成导航
吸顶；生成结果的检查按钮保留权限检查，并正确处理 HTML 布尔属性。
