# dnsmasq 普通版与完整版迁移

新版固件默认使用 `dnsmasq-full`，普通更新继续使用新镜像的包数据库，并保留
用户网络、DHCP、静态租约及 DNS 设置。差分更新则在原有事务中同时迁移程序、
依赖、包记录和安装清单，不先卸载当前 DNS 服务。

旧差分合并可能残留 `dnsmasq` 和 `dnsmasq-full` 两套记录。二者共用程序和
启动脚本；后续安装其他 APK 时，包管理器会清理旧记录，可能连带处理共用文件。
只有当完整版明确提供 `dnsmasq`，并且覆盖普通版全部程序／配置文件时，更新器
才会清理重复的普通版记录及其包元数据。保留清单等包名相关元数据不被当作独立
程序。不会删除 DNS 程序、配置、用户数据，也不处理无关包或不同的自定义实现。

这项修正也覆盖不包含 APK 数据库变更的差分包：设备上已有的重复记录会进入
同一份可恢复事务。用户自行安装的完整版继续保留其实际版本、程序和配置。

离线验证包括普通版升级、已装完整版、重复记录、连续升级和中断恢复；另用
真实 APK 工具和实际数据库快照，在隔离的小型文件系统中安装 Wi-Fi 软件包，
核对 DNS 程序、DHCP 配置、启动脚本、启用链接和其他软件包均保留。此类测试
不会启动 DNS 服务或访问设备硬件。原始快照只在本机诊断目录，不随源码交付。
