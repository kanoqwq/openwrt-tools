# OTA 文件选择按钮

原生 input[type=file] 在部分 Aurora 主题中失去按钮外观，只留下“选择文件／
未选择文件”的文字，难以辨认。补丁、基准 ZIP、新版 ZIP 和双包模式统一改为
显式的“选择文件”按钮：有底色、边框、文件夹图标、悬停及键盘焦点样式，
最小触摸高度 44px。文件名和支持格式独立显示，手机端换行，长文件名自动折行。

按钮在用户点击／键盘激活时调用原有文件输入框，文件选择本身不发起上传。
上传仍需用户确认，保留扩展名检查、权限复查、取消／卸载和固定上传目的地。
文件名使用 textContent，不解释文件名中的 HTML。没有修改后端、校验或写入流程。

  拖放、上传进度及用户确认前不生成／刷入。
