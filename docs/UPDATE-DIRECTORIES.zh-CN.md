检查范围为网页补丁导入与版本基准、差分生成／应用／回滚、独立 Diff 导出、

## 已修正的目录假定

| 路径 | 修正 |
| --- | --- |
| 网页 `.ota`／包装 ZIP、基准 `old.zip`、新版 `new.zip` | 点击选择后与拖放共用认证上传。在真正 POST 前经对应 RPC 准备固定目标目录；传输结束落盘时报 ENOENT，只重新准备并重传一次。其他写入错误不重传。 |
| Builder 生命周期 | 每次公开操作及工作进程入口重新准备自有工作目录，不只在对象构造时建立。工作目录甚至整个状态目录被清理后可重建；不会伪造丢失的基准。 |
| 差分目标父目录 | 即使目录在旧／新固件中没有变化，只要设备上缺失且有待写入文件，就将必需祖先目录加入持久事务计划。使用目标版本索引内的目录元数据；无索引旧包仅对新建目录采用 root:root 0755。 |
| 状态与锁、RAM 执行器 | 自有记录、执行工作区及锁的父目录递归创建。缺失恢复副本和硬件输入仍报错。 |
| 独立 Diff 导出 | 生成 `.ota` 和导出工具 ZIP 前创建用户选定的输出父目录。已有输出不覆盖。 |
| MU300／Pro 普通更新 | 在系统交换／分区写入之前准备 `.mu300` 启动状态目录；迁移旧服务启用链接前准备新根的 `etc/rc.d`。 |
| E5 普通更新 | 保存配置与恢复版本信息前准备新根相应父目录；Android 侧 Debian SD 更新准备 `etc/e5` 元数据目录。 |

已存在目录的权限、属主和用户文件保留。新建的差分目标目录受同一份备份、
事务与恢复记录管理；失败或手动回滚仅删除新建的空目录，保留新增用户数据。
目标祖先为文件、符号链接或不可写时仍明确停止，不自动删用户文件解决冲突。
